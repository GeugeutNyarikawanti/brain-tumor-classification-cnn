# 🧠 Brain Tumor Classification using CNN

## 📌 Project Overview

This project aims to classify brain MRI images into four categories using a Convolutional Neural Network (CNN) implemented with PyTorch.

## 📂 Dataset

- **Dataset:** Brain Tumor Classification (MRI)
- **Source:** Kaggle
- **Owner:** Sartaj Bhuvaji
- **License:** MIT License

> https://www.kaggle.com/datasets/sartajbhuvaji/brain-tumor-classification-mri

## 🏷️ Classes

- Glioma Tumor
- Meningioma Tumor
- Pituitary Tumor
- No Tumor

## 🛠️ Tech Stack

- Python
- PyTorch
- OpenCV
- NumPy
- Matplotlib
